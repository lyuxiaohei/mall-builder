# 个性化推荐组件-数据来源规则

## 猜你喜欢

取该用户在该品牌商城内最近交互过的商品分类，从这些分类中按销量取热门商品。

### 埋点

下单 点击事件 确认支付按钮 +1
加购 点击事件 点击加入购物车 +1
收藏 点击事件 点击商品详情页收藏按钮 +1

### 数据来源

| 数据        | 来源表/接口        | 筛选条件                                     | 说明              |
| --------- | ------------- | ---------------------------------------- | --------------- |
| 用户行为数据    | 品牌商城用户行为表     | 用户ID + 品牌商城ID + 近30天 + 行为类型（购买/加购/收藏SKU） | 提取用户交互过的 SKU 列表 |
| SKU商品分类数据 | 品牌商城商品表       | SKU 列表一级分类                               | 统计各一级分类出现频次     |
| 候选商品SKU数据 | 品牌商城商品表 + 订单表 | 品牌商城ID + 指定SKU的一级分类 + 近30天已支付订单数         | 按订单数倒序          |
| 兜底热销数据    | 品牌商城商品表 + 订单表 | 品牌商城ID + 全品类 + 近30天已支付订单数                | 无行为数据时使用        |

### 匹配逻辑

1. 查询该用户在该品牌商城近 30 天内**购买/加购/收藏**过的商品（不统计逆向操作如移出购物车、取消收藏），统计各一级分类出现次数，取 Top3 分类
2. 在这 3 个分类中，按该品牌商城近 30 天已支付订单的SKU商品件数，降序取商品
3. 无行为数据时，直接取该品牌商城全品类近 30 天热销商品

**滚动补充**：当用户下拉滚动加载时，若上述规则商品已全部加载完，自动开始取该品牌商城全品类近 30 天热销商品补充。

## 大家都在买

该品牌商城近 30 天销量排行。

### 数据来源

| 数据         | 来源表/接口        | 筛选条件                   | 说明              |
| ---------- | ------------- | ---------------------- | --------------- |
| SKU商品销量数据  | 品牌商城订单表 + 商品表 | 品牌商城ID + 近30天 + 已支付状态  | 按 SKU 维度聚合订单数   |
| 兜底上架数据     | 品牌商城商品表       | 品牌商城ID + 已上架 + 按创建时间倒序 | 无订单数据时使用        |

### 匹配逻辑

1. 统计近 30 天该品牌商城全部订单的SKU商品件数
2. 仅取已上架、库存大于 0 的商品
3. 无订单数据时，按商品创建时间倒序取最新上架商品。

**滚动补充**：当用户下拉滚动加载时，若上述规则商品已全部加载完，自动开始取该品牌商城全品类近 30 天热销商品补充。（本规则下排序结果与补充数据一致，用户无感知切换。）
