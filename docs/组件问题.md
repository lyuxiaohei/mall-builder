# 商城搭建编辑器组件调整方案

> 基于2026年03月31日需求评审录音整理

---

## 一、商品分组组件

### 1.1 数据来源配置弹窗

**现状问题：**
- 数据来源类型不完整，缺少部分选项

**调整方案：**

| 数据来源类型 | 说明 |
|-------------|------|
| 按品牌 | 选择品牌，展示该品牌下商品 |
| 按标签 | 选择标签，展示该标签下商品 |
| 按分类 | 选择分类，展示该分类下商品 |
| 按单品 | 手动选择具体商品（支持多选） |

**按单品模式补充功能：**
- 商品网格展示（4列布局）
- 搜索功能：支持按商品名称搜索
- 分页功能：支持翻页加载更多商品
- 多选功能：点击商品卡片进行多选

### 1.2 商品分组其他配置项

| 配置项 | 说明 |
|-------|------|
| 显示商品个数 | 每页展示商品数量 |
| 换一换功能 | 点击更换展示的商品 |
| 列表样式 | 大图单列、小图双列、小图三列、横向滑动 |
| 卡片样式 | 圆角/直角 |
| 显示价格 | 是否显示商品价格 |
| 显示划线价 | 是否显示原价（划线价） |
| 显示销量 | 是否显示已售数量 |

---

## 二、商品列表组件

### 2.1 数据来源配置弹窗

**现状问题：**
- 数据来源配置与商品分组不一致
- 缺少分类和单品类型

**调整方案：**
商品列表的数据来源配置弹窗**需与商品分组完全一致**，包括：
- 相同的数据来源类型选项
- 相同的弹窗布局和样式
- 相同的交互逻辑

| 数据来源类型 | 说明 |
|-------------|------|
| 按品牌 | 选择品牌 |
| 按标签 | 选择标签 |
| 按分类 | 选择分类 |
| 按单品 | 手动多选商品（搜索+分页） |

### 2.2 商品列表其他配置项

| 配置项 | 说明 |
|-------|------|
| 列表样式 | 大图单列、小图双列、详情列表、小图三列、一大两小、横向滑动 |
| 排序方式 | 综合排序、按销量、价格从低到高、价格从高到低、按评论数、按好评率、最新商品 |
| 卡片样式 | 圆角/直角 |
| 商品边距 | 商品卡片之间的间距 |
| 页面边距 | 组件四周的边距 |
| 背景颜色 | 组件背景色 |
| 显示SPU名称 | 是否显示商品名称 |
| 显示SKU规格 | 是否显示规格值 |
| 显示价格 | 是否显示价格 |
| 显示角标 | 是否显示角标（支持自定义角标文字或图片） |
| 购物车图标 | 购物车按钮样式 |

### 2.3 分页与加载

**讨论结论：**
- 使用"每页商品个数"参数控制显示数量
- 滚动到底部时自动加载下一页
- 或在底部显示"查看更多"/"加载更多"按钮

## 三、轮播图组件

### 3.1 跳转链接配置

**调整方案：**

| 跳转类型 | 说明 |
|---------|------|
| 内部页面 | 选择已创建的主页面或子页面 |
| 商品详情 | 选择具体商品 |
| 分类页面 | 选择分类 |
| 品牌 | 选择品牌 |
| 标签 | 选择标签 |
| 外部链接 | 输入URL地址 |

### 3.2 背景延伸功能

**需求描述：**
轮播图支持背景延伸到顶部搜索框区域，实现视觉统一。

### 4.1 功能定位

**需求描述：**
- 作为容器组件，可将其他组件包裹在内
- 统一背景色/背景图
- 支持选择包含哪些组件

**调整方案：**
1. 支持拖入其他组件作为子组件
2. 统一设置背景色或背景图
3. 可配置组件高度

## 七、悬浮组件（新增）

### 7.1 功能描述

**需求来源：** 每个页面都可能需要的悬浮功能按钮。

**支持功能：**
- 置顶按钮
- 购物车入口（显示商品数量角标）
- 客服入口

### 7.2 配置项

| 配置项 | 说明 |
|-------|------|
| 悬浮位置 | 左侧/右侧 |
| 距离底部 | 距离页面底部的距离 |
| 显示项目 | 选择显示哪些功能（置顶/购物车/客服） |
| 图标样式 | 默认或自定义图片 |

---

## 八、标题与文本组件

### 8.1 调整方案

**讨论结论：**
- 标题组件与文本组件功能重叠
- 保留文本组件，隐藏标题组件
- 文本组件可通过配置实现标题效果

### 8.2 文本组件配置

| 配置项 | 说明 |
|-------|------|
| 文本内容 | 支持富文本编辑 |
| 字体大小 | 12-24px |
| 字体颜色 | 自定义颜色 |
| 是否加粗 | 粗体/常规 |
| 对齐方式 | 左对齐/居中/右对齐 |
| 背景颜色 | 组件背景色 |
| 页面边距 | 四周边距 |

---

## 九、链接组件

### 9.1 调整方案

**讨论结论：**
- 链接组件样式较丑，功能可由其他组件承载
- 移除链接组件
- 其他组件（轮播图、图文导航等）统一支持跳转链接配置

---

## 十、通用配置项

### 10.1 所有组件需支持的配置

| 配置项 | 说明 |
|-------|------|
| 页面边距 | 组件四周的边距（上、下、左、右） |
| 圆角样式 | 组件圆角/直角 |
| 背景颜色 | 组件背景色 |

### 10.2 跳转链接统一配置

所有可点击的组件统一支持以下跳转类型：
- 内部页面（主页面/子页面）
- 商品详情
- 分类
- 品牌
- 标签
- 单品
- 外部链接

---

## 十一、价格显示相关

### 11.1 划线价字段

**需求描述：**
- 商品需要新增"划线价"字段
- 默认取电商价
- 支持在每个渠道单独修改
- 划线价低于销售价时需提示

### 11.2 显示价格配置

| 显示项 | 说明 |
|-------|------|
| 显示价格 | 销售价（必须显示） |
| 显示划线价 | 原价/市场价 |
| 显示积分 | 积分+现金组合支付时显示 |
