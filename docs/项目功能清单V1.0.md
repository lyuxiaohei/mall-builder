## 一、项目概述

### 1.1 项目定位
商城搭建系统是一个面向运营人员的可视化页面搭建平台，支持通过拖拽组件的方式快速搭建商城页面，并支持模板管理与多品牌商城管理。

### 1.2 技术栈
| 类型 | 技术 |
| --- | --- |
| 前端框架 | 原生 JavaScript (ES6+) |
| 页面结构 | HTML5 |
| 样式方案 | CSS3 (CSS Variables + CSS Grid/Flexbox) |
| 数据模拟 | 本地 Mock 数据 (data.js) |
| 运行方式 | 静态 HTML 直接运行 |

### 1.3 核心文件结构
```
mall-builder-prototype/
├── index.html          # 运营工作台主页面
├── editor.html         # 可视化编辑器页面
├── app.js              # 主页面业务逻辑
├── data.js             # Mock 数据
├── styles.css          # 全局样式
└── assets/             # 静态资源
```

```javascript
{
  id: String,           // 模板ID
  name: String,         // 模板名称
  status: String,       // 状态：draft | published | pushed
  tags: Array,          // 标签数组
  updatedAt: String,    // 最后修改时间
  useCount: Number      // 使用次数
}
```

## 三、交互特性

### 3.1 拖拽交互
- 组件拖拽添加到画布
- 楼层拖拽排序
- 拖拽过程视觉反馈（透明度变化、边框高亮）

### 3.2 状态管理
- 模板状态流转：草稿 → 已发布 → 已推送
- 页面状态：草稿 / 使用中
- 商城状态：运营中 / 已关闭

### 3.3 视觉反馈
- 卡片悬浮效果
- 选中状态高亮
- 按钮点击反馈
- 弹窗遮罩层

## 四、样式规范

### 4.1 设计变量
```css
--primary: #1890ff           /* 主色 */
--primary-hover: #40a9ff     /* 主色悬浮 */
--bg-page: #f5f5f5           /* 页面背景 */
--bg-content: #ffffff        /* 内容背景 */

--text-secondary: #666666    /* 次级文字 */
--border: #e8e8e8            /* 边框色 */
--success: #52c41a           /* 成功色 */
--warning: #faad14           /* 警告色 */
--danger: #ff4d4f            /* 危险色 */
```

### 4.2 组件风格
- 按钮遵循 Ant Design Button 规范
- 表格遵循 Ant Design Table 规范
- 弹窗遵循 Ant Design Modal 规范
- 圆角统一使用 4px/8px/12px/16px
