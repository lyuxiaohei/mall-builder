# 商城搭建系统

## 一、页面管理功能

### 页面类型管理
#### 主页面
- 首页 (home)
- 分类页 (category)
- 商品页 (product)
- 购物车 (cart)
- 我的 (mine)

#### 子页面
- 支持自定义页面名称
- 页面描述设置
- 独立组件楼层管理

### 页面模板系统
#### 首页模板
- 标准首页模板
  - 包含：搜索框、轮播图、图文导航、商品推荐、置顶功能
  - 预设完整组件配置

#### 分类页模板
- 三级分类页 (page1)
  - 左侧一级分类导航
  - 右侧二级分组与三级图标网格
- 二级分类页 (page2)
  - 左侧一级分类导航
  - 右侧二级图标网格
- 二级分类+商品列表 (page3)
  - 左侧一级分类导航
  - 右侧Tab子分类
  - 商品列表展示
- 一级分类（横向Tab）(page4)
  - 顶部横向Tab子分类
  - 商品列表展示
- 一级分类（直接列表）(page5)
  - 左侧一级分类导航
  - 右侧直接商品列表

#### 商品页模板
- 标准商品页模板
  - 商品展示模块
  - 详情模块
  - 评价模块

#### 购物车模板
- 标准购物车模板
  - 购物车列表模块
  - 结算模块

#### 我的页面模板
- 标准会员中心模板
  - 用户信息区
  - 中部导航网格
  - 功能菜单列表
- 积分商城会员页模板
  - 用户信息区
  - 积分卡片
  - 积分服务导航
- 简约会员页模板
  - 用户信息区
  - 功能菜单列表

### 页面操作功能
- 新增页面（弹窗选择类型+模板）
- 删除页面
- 页面预览卡片
- 页面切换（主页面/子页面分组）

  - 默认图标
  - 激活图标

- 默认文字颜色

- 字体大小
- 是否显示文字
- 背景颜色
- 菜单高度
- 边框颜色
- 图标与文字间距
